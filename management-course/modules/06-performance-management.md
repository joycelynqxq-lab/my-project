# 模块 06　绩效管理与辅导

## 学习目标

- 理解绩效管理是一个持续的循环，而非一年一次的评分
- 用 GROW 模型进行辅导对话
- 有效处理绩效不佳的情况

## 核心概念

### 1. 绩效管理循环

```
设定期望 → 持续跟进与反馈 → 辅导与支持 → 评估与回顾 → 重新设定期望
```

**原则：绩效评估时不应出现"惊喜"。** 任何问题都应在平时的反馈中提前沟通。

### 2. 绩效 = 能力 × 意愿 × 环境

当绩效不理想时，先诊断原因：

| 原因 | 典型表现 | 对策 |
| --- | --- | --- |
| 期望不清 | "我不知道你要的是这个" | 重新明确目标和标准 |
| 能力不足 | 想做但做不好 | 培训、辅导、配导师 |
| 意愿不足 | 能做但不愿做 | 了解动机，明确后果 |
| 环境障碍 | 资源、流程、工具问题 | 管理者负责排除障碍 |

### 3. GROW 辅导模型

辅导的核心是**提问**，而不是给答案。

| 步骤 | 目的 | 示例问题 |
| --- | --- | --- |
| G 目标（Goal） | 明确想达成什么 | 这次谈话结束时，你希望得到什么？ |
| R 现状（Reality） | 了解真实情况 | 目前进展如何？你已经尝试了什么？ |
| O 选择（Options） | 探索可能性 | 还有哪些做法？如果没有任何限制，你会怎么做？ |
| W 行动（Will） | 承诺下一步 | 你接下来具体要做什么？什么时候？需要什么支持？ |

### 4. 处理持续的绩效问题

1. **尽早沟通**：用 SBI 说明差距，不要拖延
2. **共同诊断**：倾听员工的视角
3. **制定改进计划**：明确目标、标准、期限（通常 30–90 天）和支持措施
4. **定期检查**：每周或每两周回顾
5. **记录**：留下书面记录，确保公平
6. **做出决定**：改进则认可；未改进则按公司制度处理，并与 HR 协作

### 5. 评估中的常见偏差

- **近因效应**：只记得最近的表现 → 平时做好记录
- **光环效应**：因某一方面突出而整体高估 → 按维度分别评估
- **趋中倾向**：给所有人中间分 → 依据事实拉开差距
- **相似偏好**：偏爱与自己相似的人 → 与同级管理者校准

## 角色扮演

场景：一名员工连续两个月未达成交付目标。管理者用 GROW 模型进行一次 20 分钟的辅导谈话。观察者记录：管理者提问与陈述的比例大约是多少？
