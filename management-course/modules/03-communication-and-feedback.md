# 模块 03　沟通与反馈

## 学习目标

- 建立高质量的一对一（1:1）沟通机制
- 用 SBI 模型给出具体、可执行的反馈
- 掌握积极倾听和接收反馈的方法

## 核心概念

### 1. 一对一会议（1:1）

1:1 是**员工的会议**，不是管理者的进度汇报会。

- **频率**：每周或每两周一次，每次 30 分钟，尽量不取消
- **议程**：由员工主导，管理者补充
- **内容比例**：工作进展 ≤ 1/3，其余用于困难、成长、感受与反馈

常用问题：

- 最近工作中最让你有成就感 / 最受挫的事情是什么？
- 有什么事情在阻碍你？我能帮什么忙？
- 你希望在未来半年学会什么？
- 我作为管理者，有什么可以做得更好的？

### 2. SBI 反馈模型

| 要素 | 含义 | 示例 |
| --- | --- | --- |
| S 情境（Situation） | 何时何地 | 在周二的客户评审会上 |
| B 行为（Behavior） | 可观察的具体行为，不评价人格 | 你打断了客户三次 |
| I 影响（Impact） | 该行为带来的影响 | 客户后来表示没机会说完需求，会议没有达成结论 |

进阶：**SBI + 提问 / 期望**——"你怎么看？" "下次我们可以怎么做？"

正面反馈同样适用 SBI："在昨天的故障处理中（S），你主动整理了时间线并同步给所有相关方（B），大家因此少开了两次会，问题提前一小时解决（I）。"

### 3. 积极倾听

- **专注**：放下手机、关掉消息提醒
- **复述**："我理解你的意思是……对吗？"
- **追问**："能多说一点吗？" "具体是什么情况？"
- **先理解，再回应**：不急于给建议或辩解

### 4. 接收反馈

1. 感谢对方（给反馈需要勇气）
2. 澄清而非辩解
3. 判断是否采纳，并告知对方你的后续行动

## 工具：1:1 会议记录模板

```
日期：
员工议题：
管理者议题：
上次行动项回顾：
本次讨论要点：
新行动项（负责人 / 截止日期）：
```

## 角色扮演

两人一组，一人扮演管理者、一人扮演员工。场景：员工近两周多次延迟提交周报，管理者用 SBI 给出反馈。观察者记录：是否具体？是否评价了人格？是否给对方表达空间？

## 自测题

1. 把"你做事太不靠谱了"改写为一条 SBI 反馈。
2. 1:1 会议的主人是谁？为什么？
3. 接收反馈时的三个步骤是什么？

## 本周行动

与每位直接下属进行一次 1:1，并至少给出一条正面 SBI 反馈。
