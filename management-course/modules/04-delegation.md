# 模块 04　授权与委派

## 学习目标

- 识别哪些工作应当授权
- 根据员工的能力与意愿选择领导方式
- 用结构化方法完成一次授权，并设置合适的跟进节奏

## 核心概念

### 1. 为什么难以授权

- "我自己做更快"
- "别人做不好，最后还要我返工"
- "这件事交出去，我的价值在哪里"

这些想法短期正确，长期却会让管理者成为团队瓶颈，团队也无法成长。

### 2. 应当授权什么

| 类型 | 是否授权 | 说明 |
| --- | --- | --- |
| 重复性、流程化工作 | 优先授权 | 管理者做性价比最低 |
| 能促进员工成长的工作 | 积极授权 | 带有挑战的"伸展任务" |
| 员工比你更擅长的工作 | 应当授权 | 发挥专长 |
| 涉及保密、人事、绩效评定 | 谨慎 / 不授权 | 属于管理者的核心职责 |

### 3. 情境领导：按成熟度调整方式

| 员工状态 | 能力 | 意愿 | 领导方式 |
| --- | --- | --- | --- |
| D1 热情的新手 | 低 | 高 | **指导型**：明确告知做什么、怎么做 |
| D2 受挫的学习者 | 中低 | 低 | **教练型**：既给指导，也给鼓励 |
| D3 谨慎的执行者 | 中高 | 不稳定 | **支持型**：倾听、鼓励，让其参与决策 |
| D4 独立的高手 | 高 | 高 | **授权型**：交代目标，放手执行 |

同一个人在不同任务上的成熟度可能不同。

### 4. 授权五级

1. 去了解情况，向我汇报，由我决定
2. 提出几个方案，由我选择
3. 给出建议方案，经我批准后执行
4. 自行决定并执行，事后告诉我结果
5. 自行决定并执行，无需汇报

授权时要明确说出是**第几级**，避免"我以为你会先问我"的误会。

## 工具：授权清单

授权一项工作时，确认以下内容已说清楚：

- [ ] 期望的结果是什么，成功的标准是什么
- [ ] 为什么这件事重要
- [ ] 截止时间与关键里程碑
- [ ] 可用的资源与预算
- [ ] 授权级别（1–5 级）
- [ ] 跟进的方式和频率
- [ ] 遇到问题找谁

## 案例

王经理把年度客户大会的筹备交给入职半年的小张，只说了一句"你看着办，有问题找我"。两周后发现场地还没定，王经理很生气，小张也很委屈。

**讨论**：用情境领导和授权五级分析问题出在哪里，并重新设计这次授权。

## 自测题

1. 一位能力强但最近积极性下降的员工，适合哪种领导方式？
2. 授权五级中，第 3 级和第 4 级的区别是什么？
3. 哪些工作不适合授权？

选择一项你目前亲自做的工作，用授权清单完成一次授权，并约定跟进时间。
