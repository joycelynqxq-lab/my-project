# 学习日志

每完成一个模块，复制下面的模板，记录"本周行动"的实践情况。

```
## 模块 __：____________

日期：
本周行动：

我做了什么：

结果如何（对方的反应、产生的变化）：

我学到了什么：

下次我会怎样做得不同：
```

## 结业项目模板

```
# 结业项目：____________

## 1. 问题描述
（团队中的真实问题，现状如何，有什么数据或事实）

## 2. 原因分析
（运用了哪些模块的工具？发现了什么？）

## 3. 行动计划
| 行动 | 负责人 | 截止日期 | 使用的工具 |
| --- | --- | --- | --- |

## 4. 衡量指标
（如何判断问题已改善？）
```
