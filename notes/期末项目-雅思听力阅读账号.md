# 期末项目：雅思听力+阅读经验分享账号

- 平台：抖音、小红书（双平台运营）
- 形式：短视频（真人出镜/图文卡片+配音，待定）
- 个人背书：雅思 7.5

## 一、产品定位与目标市场

**定位**：面向雅思备考人群的"听力+阅读"垂直干货账号，人设为"雅思7.5学长/学姐，只讲听力阅读怎么冲分"。

- 不做泛雅思内容（口语、写作暂不涉及），聚焦两科，便于建立专业感、避免同质化
- **目标市场**：正在备考雅思、目标分数 5.5–7 分、卡在听力/阅读单项的学生群体（以准备留学的大学生为主）
- **差异化**：多数雅思账号泛而不精，本账号主打"方法论+可复制步骤"，而非单纯经验炫耀

## 二、设计思路与制作过程

**内容系列规划（示例选题）**

听力篇：
- [ ] 听力从 X 分冲到 8.5 分的方法论（个人经历引流）
- [ ] 精听 vs 泛听怎么选、怎么练
- [ ] 高频听力陷阱题型拆解（同义替换、干扰项识别）
- [ ] 场景词汇整理（租房 / 图书馆 / 校园场景等高频场景）

阅读篇：
- [ ] 阅读时间分配技巧（每篇控制在多少分钟）
- [ ] 三大题型（判断题 / 选择题 / 填空题）做题步骤拆解
- [ ] 长难句精读方法
- [ ] 真题错题复盘 vlog

**制作流程**：选题 → 脚本/大纲 → 拍摄或图文卡片制作 → 剪辑（剪映）→ 配文案+标签 → 发布 → 收集评论反馈迭代下一期

## 三、营销目标

（需要设定具体、可衡量的目标，例如：）
- 项目周期内（建议 2–4 周）抖音 + 小红书合计涨粉 ___ 人
- 单条视频最高播放量达到 ___
- 收集到 ___ 条评论区真实提问/私信互动，作为内容"有用"的证据

## 四、营销策略

- **内容策略**：垂直深耕听力+阅读，不铺开做泛雅思号，强化专业人设
- **标题/封面（抖音）**：结果导向型标题，例如"听力 X 天从 6 冲到 8.5"，突出反差和具体数字
- **关键词/标签（小红书）**：覆盖"雅思听力技巧""雅思阅读方法""雅思备考"等搜索词，靠 SEO 获取自然流量
- **发布节奏**：固定更新时间/频率，培养粉丝期待
- **互动运营**：评论区置顶提问、引导私信提问、根据粉丝反馈调整选题（例如"猜题"系列）
- **冷启动**：先在班级群/朋友圈/雅思备考群分享获取第一批真实互动，同时作为报告的证据材料

## 五、营销效果（需在项目结束后回填，并附截图证据）

- 数据指标：播放量、点赞、收藏、评论数、涨粉数（发布前后对比）
- 质性反馈：粉丝私信/评论区真实提问和好评截图
- 有效性验证：是否有粉丝反馈"确实帮到了备考"
